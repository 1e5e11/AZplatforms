01 / SCENARIOS

四种基础场景

模式决定布局密度、字体重心和视觉力度。颜色 token 保持一致，按场景调整使用权重。

01 / DEFAULT

默认模式

用于内容页、产品介绍、普通功能页面和阅读型界面。

布局
区块间距至少 --space-16（64px）；卡片内距至少 --space-6（24px）。
字体
标题用 --font-display-cn，界面控件用 --font-heading-cn，长文用 --font-body-cn。
色彩
米色底 + 浅色内容面板，橙色只提示主要行动和重点。
使用方法
正文控制在 65ch 内，单屏最多 3 层视觉重点；以不对称留白建立节奏。
查看默认规则 ↗
02 / BRAND

品牌增强

用于官网首页、落地页、营销页、品牌专题与宣传场景。

布局
可以放大标题与负空间，让主视觉略微打破网格。
字体
大幅使用衬线标题，配少量无衬线说明与导航。
色彩
可使用最多 2 色的受控渐变，整页不超过 3 个渐变区域；主 CTA 仍用暖橙。
使用方法
用一处鲜明的排版或几何图形做记忆点，动效优先变换 transform 与 opacity。
查看模式隔离 ↗
03 / DATA

数据密集

用于 Dashboard、监控、分析报表、指标与图表页面。

布局
区块间距约 --space-10（40px）；卡片内距可收至 --space-4（16px）。
字体
关键数字用衬线，辅助数字用等宽体；开启 tabular-nums。
色彩
边界提高到 --color-border-default；图表系列按橙、灰蓝、橄榄绿、沙棕、灰排序。
使用方法
一屏突出最多 3 个指标；颜色传递语义，其他数据用位置、字号和形状区分。
查看 Dashboard 专项 ↗
04 / UTILITY

工具优先

用于后台管理、配置、权限、CRM、ERP 与专业工作台。

布局
信息密度优先；内容区常用 --space-4（16px），区块间距约 --space-8（32px）。
字体
标题和控件统一偏向无衬线，方便快速扫读。
色彩
用 --color-border-default 分区，弱化阴影；危险操作明确用 --color-error。
使用方法
保持操作位置稳定、表单反馈及时，默认关闭装饰性过渡。

03 / COLOR SYSTEM

每一种颜色，用在哪里

下方完整列出 assets/base.css 的 21 个基础颜色。点击任一行的 token 可复制 var(...)。

用色顺序

先用背景色建立层级，再用文字与边框定义可读性；强调色只服务主要操作。状态色只表达成功、警告、错误或信息，不做装饰。

对比度提醒

仓库原始暖橙色 #D97757 配浅白文字约为 2.96:1，不足以承载常规字号按钮文案；按钮上宜使用深墨色 --color-text-primary。暖橙或深暖橙在浅底上作小字时，也应再测试对比度或改用更深的同色系文字色。

语义别名与透明色

ALIASES

下面的别名也定义于 base.css。它们优先用于具体语义，方便未来换主题时集中修改。

暗色模式

base.css 已为背景、文字和部分边框提供 prefers-color-scheme: dark 覆写；状态色和强调色沿用同一语义。实际项目应再检查正文、图表、禁用态与悬浮层的对比度。

08 / VISUAL LANGUAGE

视觉模式与 Logo

在遵守基础 token 的前提下，用背景、排版、网格和几何建立独特气质。

BACKGROUND

背景与深度

米色画布上可叠轻微径向晕染或噪点；深浅区块交替形成阅读节奏。同一项目选择 1–2 种背景技法。

COMPOSITION

空间构图

正文保持可读行宽；用不对称留白、超大标题或局部突破网格建立视觉重点。

MOTION

动效与微交互

进入动画可用自下而上淡入，错落延迟约 80ms；悬停位移保持轻微，尊重减少动画偏好。

ACCESSIBILITY

可访问性

正文目标对比度至少 4.5:1，大标题至少 3:1；焦点可见，移动端目标至少 44×44px。

LOGO SYSTEM

Logo 几何

从 8×8 或 12×12 网格、圆与基本多边形开始，统一笔画厚度；有机圆角和负空间应有明确作用。

LOGO VERSIONS

Logo 变体

准备彩色、深底反色、单色和仅图标版本；再检查最小尺寸、安全间距、Favicon 与 App Icon。
